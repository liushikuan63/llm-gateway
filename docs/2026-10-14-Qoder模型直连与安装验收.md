## 实现范围

- `src-tauri/src/proxy/qoder.rs`：固定 Global/CN 官方区域目标，私有账号/设备/模型凭据代次快照，账号目录缓存，独立 HTTP 编码 POST，取消/到期检查，有限 SSE 与非流式聚合。生产不需要 Qoder 客户端、CLI、SDK 或本机桥接。
- `src-tauri/src/qoder_auth/model.rs`：本软件加密记录提供授权材料；模型调用不自动签发、刷新或重登；前后校验代次与有效期，不把认证材料返回 IPC。
- 复用原有网关运行时、别名、模型覆盖、五协议转换、预算和审计。旧 `qoder`/`qoder-cn` CLI 运行时保留兼容；新增 `qoder-model` 必须明确区域及本机账号。
- `GatewayError::NoReplay`：关闭客户端 HTTP 重试、鉴权确认复测和失败转移重放；真实 HTTP 状态、错误分类及逐跳审计仍保留。SSE 权威结束失败不能变成成功回复。
- 账号登记复用原子事务：重复接入只追加未见 upstream，保留停用、别名、能力、价格及运行时设置；冲突或插入失败完整回滚。Qoder 与 WorkBuddy 共享实现，各自有回归。
- 页面显式准备/刷新模型认证和接入目录，进入页面仅读本机状态。格式校验、忙碌状态、键盘、失败反馈、账号切换与迟到结果保护已接入。供应商目录发现及测试按钮走实际账号分派。
- 目录上下文和输出上限保留已声明值；缺失值不猜测。积分倍率不转换为现金价格，工具/音视频的目录未知能力保留未知；完整多轮、工具和图片协议目前是夹具验证。
