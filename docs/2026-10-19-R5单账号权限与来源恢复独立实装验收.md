## 行为与并发合同

`account_auto_claim` 按 slot 控制自动 tick、直接自动入口及 headless；APP 全量保存新增账号或同 ID 更换平台时默认关闭，旧缺字段配置保留兼容。窄 IPC 按整个权益配置 revision 做 CAS，持久化成功后发布，旧全量保存、导入和快照不能重新开启已经关闭的 slot。账号 disabled 或全局 auto 关闭时允许提前设置本地权限；保存失败或响应丢失先读回，不重发。

APP 全量保存、快照、导入、窄权限和搜索配置提交在同进程共享异步锁内串行。Windows 任务注册可能部分成功再返回错误，协调器在首次注册失败或配置写失败后按最新配置恢复；恢复不确认明确报错。CLI 显式安装仍强制修复任务；该锁不提供跨进程配置 CAS。注释、实现及失败边界见[多账号 Wiki](wiki/multi-account-acceptance.md)。

已验证 native 主体不解除同日不可归属旧预约；原 slot 的 GET 对账、陈旧来源零 mutation、已开始发送的晚结果归原主体和 HTTP 错误无 fallback 重发保持。缺设备上下文的旧 Trae 保存来源保留查询、拒绝领取，恢复原凭据不会伪造设备或可信 UID。
