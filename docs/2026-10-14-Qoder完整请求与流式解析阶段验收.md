## 当前实现

- `src-tauri/src/qoder_auth/request.rs` 从现有 ChatRequest 构造 RemoteChatAsk；保留全部消息顺序、system、多轮历史、工具调用及配对结果、图片 URL/细节，映射 max_tokens、采样、stop、工具选择和思考强度。明确拒绝未验证的音视频、扩展参数、缺失结果的工具历史、未启用模型及未声明的图片/思考能力，不静默删内容。没有把构造成功视为平台接受请求。
- `scripts/qoder-protocol/inference.cjs` 与严格私有 worker 接入两区固定 URL、模型/source 一致性、原始 UTF-8 body 编码及 body/path 签名。使用内置 Node crypto，不依赖客户端、SDK、CLI、WASM 或本机 HTTP 桥接；生产资源列表只加入自己的 inference.cjs，合成 oracle 不打包。
- `src-tauri/src/qoder_auth/stream.rs` 解码外层 HTTP 信封中的内层 OpenAI JSON。内层 DONE/finish_reason 不代表权威完成，只有外层 event:finish 可以发布 Finish/Done，提前 EOF、失败信封、无有效输出或计数异常失败。保留晚到的输入/输出/缓存/思考 Token 和平台积分；积分不是货币单价。
- 工具按 ID 区分，即使上游新调用重复 index 0，也分别保留完整名称与 JSON 参数。工具片段在完整组装、认证反射检查后一次发布；正文、思考和拒绝输出保留最长认证串减一的 UTF-8 安全尾部，权威结束时在 Finish 之前发布。短响应可能在结束时才发布，这是当前认证材料保护的行为边界。
- Rust 实际私有管道回归连接请求构造、两区签名、独立 codec 解码，核验原始完整 body；输出限额由 4 MiB 调整为 8 MiB，以容纳 4 MiB 原始输入编码后的膨胀。Rust/worker 输入统一为 9 MiB：二次 JSON 转义最多约 8 MiB，另留 1 MiB 有界信封预算，保留 4 KiB stderr、10 秒与自有进程清理约束。4,194,304 字节反斜线密集 raw 实际成为 8,389,269 字节管道输入，同一独立解码对照先失败再通过。

公开参考限定为协议事实：固定提交 `b8b595fabbed733c5899019fed4b660ea23d94e0` 的 [RemoteChatAsk 与流式协议](https://github.com/Liki4/qodercli2api/blob/b8b595fabbed733c5899019fed4b660ea23d94e0/openai.go)、[参数与用量字段](https://github.com/Liki4/qodercli2api/blob/b8b595fabbed733c5899019fed4b660ea23d94e0/convert.go)。请求字段同时定向核对本机公开产品 worker，未读取凭据文件。自己的低层签名向量以当前 298606-byte 公开模块的合成独立对照为准，没有复制 AGPL 实现，也没有采用上游自动重试、请求转储、客户端凭据目录或全部网卡监听方案。
