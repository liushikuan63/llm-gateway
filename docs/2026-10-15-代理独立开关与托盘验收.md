## 已安装行为

- 设置页提供两个独立运行开关及两项独立“随软件启动”选项。启动选项默认 false，打开界面不会无条件启动网关或写系统代理。已有 Windows 代理只读显示来源和状态。
- 托盘提供“LLM 网关服务”和“系统网络代理”两项勾选菜单。与界面使用相同后端控制器；状态、忙碌、错误和外部变更同步，不因代理菜单点击主动打开主窗口。
- 网关开启确认实际绑定，停止只操作自有任务；端口冲突不冒认外部服务。关闭会通知已经接受的连接停止接收新请求，再等待最多五秒。已发出的模型请求可能继续完成，不能把此开关解释为平台任务取消。
- 系统代理使用 WinINet 默认 LAN 连接设置；保护手动代理、PAC、自动检测和恢复目标。每次写前先加密持久化实际原状态、恢复目标与精确计划状态，读回不确定时保留恢复副本。仅完整实际快照匹配自有状态时认定归属；外部变更不盲目覆盖。
- 系统代理地址不能使用默认、保存配置或实际正在监听的 LLM API 端口。退出软件时先恢复仍由本软件启用的系统设置，再停止自有 VPN 内核；用户手动关闭及外部修改保留。
- 控制面板、日志和账号管理在网关关闭时仍可用；聊天发送会明确提示先开启服务。未自动启动 WorkBuddy/Trae，没有新增收费请求或手动领取。
