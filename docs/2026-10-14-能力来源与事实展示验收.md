# 能力来源与模型事实首批验收

本批承接持续目标 S1/S6 和 UX3/UX6/UX7/UX8，复用现有能力来源、价格、模型声明与路由解释。没有新增依赖、数据库列、评分权重或收费评测。S1/S6 整卡仍有使用样本、来源时效、协议能力合同等后续项，不能据首批通过称全部完成。

## 已实现的行为

供应商保存现在在同一写事务里读取旧来源和定值。同供应商的同 alias/upstream/path/type 保留来源；唯一目标的别名改名可继承，重复目标不猜。对于无法归属到当前模型的载荷，如果旧供应商已有来源账本，就清空该行旧定值，防止同时改别名和上游、期间导入新来源后仍带回陈旧质量分。新供应商和无旧账本的配置分仍兼容；新目标的有来源质量应通过明确的能力导入路径写入。

编辑器更换实际上游、请求路径或用途时清除携带的分值；恢复原目标时恢复原配置。上游身份比较与保存使用相同 trim 口径。原始模型只存在本地草稿，保存前剥离，不扩大 IPC 契约。来源未知字段原样保留，损坏 JSON 仍按既有读取规则降级，不包装成有效来源。

能力页先展示模型事实：配置价格、零价、缓存计价、条件价与币种、上下文、用途、工具/思考/媒体/流式声明及四个质量维度的来源覆盖。旧配置分值、缺来源与供应商回退分分别说明；质量账本为空不会隐藏已有价格和声明。支持搜索、20 行分页、键盘、深色、窄屏局部横向滚动；部分读取失败保留可用结果并说明可能保留旧内容。成本评分关闭、无可比价格和其他缺样本分开标注。缺少价格来源时间、真实延迟/质量/效率样本仍明确提示。

通用 Ollama 目录补齐明确 thinking 能力位；缺失/非法数组保持未知，不按模型名字猜。供应商编辑器增加思考/推理开关，保留已声明能力且可关闭。
