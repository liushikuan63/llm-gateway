## 架构与边界

保留现有快速扫描及其 partial 语义；新增显式完整历史后台任务。只从现有 Codex、DSH 正式/Beta、Qoder CLI 已知日志入口读取，不接受前端任意路径，不扫描第三方凭据。单活跃任务，页面离开后仍属于原任务，重挂可查询并接续；重启后已中断任务不会自动读取，用户明确继续时校验快照与游标，失败时保持失败而非从零静默开始。

任务固定文件身份、长度和读取范围；每批有字节游标及身份/已读前缀哈希。追加尾部不混入本次快照；截断、替换、内容改写与链接切换不得导致混算。取消在批边界响应，只有已原子保存的游标和投影有效；继续前验证同一身份与已读范围，不复用仅靠日期/路径的旧状态。

数字投影、计数、游标和阶段元信息可进入本软件自有任务目录的独立辅助 SQLite（复用已有 sqlx，绝不迁移/改变用户 gateway.db）。提示词、回复、工具参数、隐藏思考、令牌与凭据不进入任务持久化。超大 JSON 行采用选择性字段解析/流式跳过无关字段，不能因大消息行截掉后续明确用量。正在写入的未完整尾行单独说明。

复用现有累计差分、现代 response_id 去重、父子前缀证明、模型与供应商归属、逐事件费用与未知区间；任务处理阶段可使用数字投影，但不得将原始头位置、文件完整性、原始 session 身份、Qoder 请求去重边界变成伪证明。取消/失败/读取不完整结果不能显示为完整账单。进度读取覆盖与用量字段未知分开，100%文件读取不等于已知账单。

## 固定 IPC 与界面合同

新增 start_client_usage_job(fromDay,toDay)、get_client_usage_job(jobId)、get_current_client_usage_job()、cancel_client_usage_job(jobId)、resume_client_usage_job(jobId)。目录和价格由后端选取，前端不传路径/价格/游标。JobView 字段：job_id、state（running/completed/cancelled/interrupted/failed）、phase、from_day、to_day、files_total、files_done、snapshot_bytes_total、snapshot_bytes_read、records_scanned、cancel_requested、coverage_complete、message（静态脱敏文字或null）、report（原 ClientUsageReport 或null）。只有 completed 可呈现新报告，partial 说明原样保留。

完整读取与快速读取分别可选；不自动扫描。轮询 job 只读本软件任务状态；晚返回、卸载及新一轮请求不得覆盖当前结果。用户取消后不自动继续，重挂页面提供继续或重新开始；进行中禁止同时开第二任务。日期筛选仍驱动总量和曲线；已有数据保持其原范围标识，不混入新任务的部分进度。
