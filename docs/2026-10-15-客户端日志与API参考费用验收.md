# 客户端日志与 API 参考费用阶段验收

本阶段按用户优先级补齐 Codex 等客户端日志的 Token 与 API 等价费用展示，沿用只读、有界扫描。Trae CN/国际版、WorkBuddy CN/国际版、Qoder CN/国际版分别保留在持续目标中；本阶段不新增平台登录或收费模型请求。

## 已实现

- Codex 现代 usage 按请求计价，再合并日曲线及所选范围。单次输入档位不会错误地按全天 Token 总量选择。
- 读取输入、输出、缓存读取和缓存写入；支持现代嵌套缓存字段。缓存属于输入子项，推理属于输出统计，不重复相加。
- 旧累计快照保留可确认差分。仅当增量与 `last_token_usage` 对齐时使用单次档位与时间；未对齐的窗口、DSH 日账本采用保守区间。未知输入或输出仍无法计价。
- 优先使用本机供应商模型参考价，并匹配显示名、内部 ID；固定官方 OpenAI API 主机可匹配 `openai` 元信息。同模型配置冲突、供应商不匹配或归属冲突保留未知。
- 无本机同模型价时，已识别的 OpenAI Codex 模型使用 2026-10-14 核验的标准 API 参考价，目前覆盖 `gpt-6.1-sol`、`gpt-6-astra`、`gpt-6-sol`、`gpt-6-luna`。输入严格大于 272K 才使用长上下文档。缓存写入缺失不能假设为 0。
- 界面按所选范围每来源/供应商/模型一行；USD/CNY 费用分别合计，未知费用不按 0 加入。费用曲线支持币种选择、上下界、键盘选择日期；窄屏曲线和表格局部横向滚动。

公开口径来自 [OpenAI 定价](https://developers.openai.com/api/docs/pricing)、[Prompt caching](https://developers.openai.com/api/docs/guides/prompt-caching) 与对应模型页。金额是标准 API 等价参考；不含服务层/地域溢价、工具费、订阅或 Credits 兑换，不代表实际账单。Qoder 输入/缓存字段口径尚未确认，不因占位零值推算费用。
