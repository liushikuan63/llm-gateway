# A4 · owner 待标注清单（30 条）

## 怎么用

每条只缺一个 `label`，取值三选一：`simple` / `vision` / `reasoning`。

- **`simple`** —— 一句话能答完，不需要读你现有的代码或环境上下文
- **`vision`** —— 请求里真的有图片/视频（**不看文本写了什么**）
- **`reasoning`** —— 要读输入再推导、排查、权衡，或在长上下文里维持计划

**判断时请只看题目本身，别参考我的任何暗示** —— 这份清单刻意打乱了顺序、
没有分组、也没有标出每题想考什么。你被我的预期锚定的话，
它就退化成「自证」，A4 这卡的意义就没了。

填法二选一：

1. 直接在本文件的表格里填，然后把文件给我；
2. 更省事：在对话里回 `1=simple 2=reasoning 3=vision ...` 这样的列表，我来合并。

`note` 字段留空即可，我会补上「为什么这么标」的说明（那是我的活，不是你的）。
