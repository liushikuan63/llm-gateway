## 实现范围

- OpenAI Chat Completions、Anthropic Messages、Responses、Ollama 入站协议，经统一中间表示调用 OpenAI、Anthropic、Gemini、Ollama 上游；保留工具调用、工具结果、多模态内容与流式生命周期。
- SQLite 持久化上下文。客户端回传 `X-Session-Id`，或设置每段会话唯一且稳定的 `user` 值，即可恢复既有会话。未带会话标识的首请求生成独立匿名 ID；相同首问不会合并会话。
- 超长历史自动压缩，摘要计入容量预算；工具调用与结果作为完整交换保留。摘要失败时保留必要近期内容，切换到较小窗口的模型前重新检查容量。压缩后重放旧历史不会重复追加。
- 上游 429、可重试 5xx、网络故障和伪成功响应可进入候选降级链。401/403 按配置鉴权故障终止当前请求；已经开始输出的流不能透明重放，异常中断会记录失败并向客户端报告，避免假成功和重复输出。
- API Key 使用 AES-256-GCM 加密入库；Windows 主密钥使用当前用户 DPAPI 封装。旧文件迁移保留同一把 AES 密钥，EFS 文件的迁移支持恢复信封与中断恢复。
- 本地监听、独立远程访问 Key、会话命名空间隔离、限流、反向代理 HTTPS 校验，以及关闭窗口驻留托盘。

探测只发送最小文本请求，最大输出预算为 128 tokens；读取本机用户环境变量，不把真实凭据写入仓库。测试账户和免费模型可用性会随上游状态变化。

| 上游 | 环境变量 | 本次结果 |

| 智谱 Anthropic 兼容端点 | `LLMGW_LIVE_BIGMODEL_KEY` | HTTP 200 负载返回 `success:false`；网关将其识别为可重试 502，未通过可用性探测 |

## 安装包与运行边界

安装包位于 `src-tauri/target/release/bundle/`。构建工具使用 Tauri 的项目缓存 `target/.tauri/`，由 Tauri 下载并校验哈希；配置参考 [Tauri useLocalToolsDir](https://v2.tauri.app/zh-cn/reference/config/#uselocaltoolsdir)。

NSIS 使用当前用户安装、简体中文和英文界面；MSI 保持固定升级标识。当前产物未配置代码签名，WebView2 缺失时由安装程序下载运行时。本次完成构建与协议测试，未执行安装/卸载回归、干净 Windows 机器验收、真实域名 TLS 部署或所有第三方客户端逐一验收。
