# LLM Gateway 桌面包快速开始

本次交付包含软件内集成的 WorkBuddy/Trae 桥接、Node 运行环境、Mihomo 与 Xray 内核。完整离线说明见同目录的 `使用手册.html`，软件内也可打开使用手册。

1. 安装 `LLM Gateway_0.2.1_x64-setup.exe`，然后用桌面 `LLM Gateway` 快捷方式启动。MSI 是替代安装格式，通常选择 EXE 即可。本机安装路径为 `D:\Program Files\LLM Gateway`。
2. 已有 API：进入供应商页，填写上游地址与 Key，读取/选择模型并测试。统一客户端地址通常是 `http://127.0.0.1:15721/v1`，以软件当前设置为准。
3. 独立账号：进入「客户端接入」。WorkBuddy 国际版在官方网页同意授权后点「接入模型」。Qoder 国际版/CN 分别网页登录，再点「准备模型认证」和「接入账号模型」。这些步骤不发送模型提示词，无需启动对应客户端、CLI 或桥接；实际模型测试可能消耗账号额度。
4. 已有客户端：WorkBuddy/Trae 可继续选 EXE、保存设置、启动客户端，再启动内置桥接；已就绪后点「接入网关」。Qoder 也保留已有 HTTP 服务与「接入 Qoder CLI」入口。软件包携带原有桥接与 Node，已有配置不会自动转换成独立账号。
5. VPN：打开「VPN 与代理」。Mihomo 点击「安装内核」后导入 Clash YAML 或 HTTPS 订阅，启动并选择节点；Xray 已随包携带，导入从 v2rayN 等导出的 Xray JSON，再启动。FlClash 使用同类 Mihomo 内核，无需再装 FlClash 才能使用本软件内核。
6. 内核启动后，再明确选择「网关使用此 VPN 代理」或「网关使用 Xray」。它们只控制网关上游出口，不自动修改 Windows 系统代理或开启 TUN。停止内核保留出口绑定，需要显式取消或重新启动。

默认端口：网关 15721；Qoder HTTP 8790；WorkBuddy 桥接/CDP 8791/9224；Trae 桥接/CDP 8792/9226；Mihomo 代理/控制 17890/17909；Xray HTTP/SOCKS 17891/17892。可在软件内修改，冲突时不要停止来源不明的进程。

Trae 的模型名为 `trae-desktop`，使用客户端当前选中的模型，桥接不切换具名模型。已有聊天草稿时会拒绝发送，一次只处理一个生成。两家桌面桥接暂只支持文本；Trae 的 SSE 在回复完成后返回。真实模型测试可能消耗账号额度。

若已有 WorkBuddy/Trae 桥接正在运行，软件会标为「外部服务」，可直接接入；「停止内置桥接」不会停止外部进程。要使用内置桥接，可以改用空闲端口。退出软件停止其自有桥接和内核，客户端本身继续运行。关闭主窗口仅隐藏到托盘，完全退出请用托盘菜单。

改桥接端口前先停止内置桥接，再保存新端口并启动；软件会同步更新仍指向旧桥接地址的已登记供应商，保留模型价格、备注、别名与停用状态。手动定制的供应商地址保留，冲突时在供应商页核对。Trae 发送前若检测到用户改了草稿或切换会话，会保留用户内容并停止本次发送。

用户数据通常位于 `%LOCALAPPDATA%\llm-gateway`；`gateway.db`、`master.key`、VPN 节点与账号配置是私有数据。更新安装会保留它们。桌面包不包含你的账号、密钥或订阅。本机更新前的备份位于 `D:\UserData\llm-gateway-backups`，不要将备份公开分享。

核对文件完整性可在此目录打开 PowerShell 运行 `Get-FileHash -Algorithm SHA256 -LiteralPath '.\LLM Gateway_0.2.1_x64-setup.exe'`，与 `SHA256SUMS.txt` 对照。内置可执行文件启动前也会校验 SHA-256。完整验收结果以本次随包的验收摘要为准；就绪、原生启动和远程节点连通性是不同判据。

接入后可进入「聊天测试」，选择「自动路由」或具体供应商模型，输入一句短消息验证。发送使用实际账号额度；打开页面和刷新评分不调用模型。支持多轮文本聊天，显示真实路由、耗时、降级与已报告用量。失败不自动重试，保留输入。客户端模型与其他运营商共享原有评分和路由规则，停用模型不参选。

`SHA256SUMS.txt` 校验交付目录里的安装包和说明文件，`source-inputs.json` 记录构建来源及源码输入摘要，二者随桌面交付包保留，不是运行依赖。安装目录的 `resources\release` 包含精简 `build-info.json`、离线 HTML 手册和快速开始。安装包无法在自身内部保存自身最终 SHA-256，因此完整校验清单保持外置。
