# 0.1.1 验证记录

验证日期：2026-09-10。本文记录 0.1.1 的界面、模型目录、客户端配置备份、托盘和额度查询增强。[0.1.0 验证记录](验证记录.md)保留上一阶段协议、上下文续接、自动压缩和失败降级的实现与真实聊天探测结果，不作为本版本安装包的校验值。

## 本轮变化

- 供应商页面、配置弹窗和导航重排，提供浅色/深色主题、筛选、批量添加模型、复制不带密钥的停用配置。
- OpenAI 兼容、Anthropic、Gemini、Ollama 模型发现；规范完整聊天地址，处理分页和上下文元数据，未知长度默认 32,768，保留手工覆盖。
- 含冒号的完整模型 ID 优先匹配，兼容 OpenRouter `:free` 和 Ollama `:latest`，仍支持供应商限定。
- 会话列表与详情适配窗口宽度，长摘要独立滚动，保留工具记录，防止快速切换请求串台。
- Claude/Codex 接管先创建唯一备份并逐字节核验，所有备份成功后才写入；Codex 采用独立供应商配置并清理该供应商内冲突的认证字段。Gemini CLI 因缺少原生入站协议暂不开放自动接管。
- 托盘由 Rust 单点创建，合并图标资源、左键恢复和右键菜单；删除配置文件中的重复托盘声明。
- 只读额度查询支持 OpenRouter、DeepSeek、New API、Sub2API；明确区分账户、Key、模型与订阅范围，缺失数据不显示为 0，不将 Key 到期解释为订阅到期。
- 初次使用引导提供五个步骤、页面导航、前后翻页和跳过/完成记忆；已有供应商不强制弹出，数据读取失败不误判为首次使用。
- 顶部使用帮助可重新打开引导或搜索离线手册；14 个章节从相同 JSON 内容生成内置阅读器、Markdown 和可打印 HTML，发布检查要求内容与版本保持一致。

## 界面验证

在 Windows 已安装的 Edge 中运行 `npm run verify:ui`，使用隔离的 IPC 测试数据。已通过模型目录获取、地址规范化、免费筛选、上下文默认值与手工覆盖保留、去重、保存失败、会话搜索和切换竞态、工具记录展开、手动压缩、删除、备份路径展示、额度适配器切换竞态、未知值/错误处理、主题和浏览器预览隔离。

追加验证首次自动引导、前后步骤、跳过/完成的持久化、帮助重开与页面导航；确认导航过程中没有供应商保存、测试模型或客户端配置写入。读取配置或供应商失败时不自动弹出引导。手册的目录、搜索、无匹配结果、代码示例和响应式布局均通过；独立 HTML 手册有 14 个锚点章节，没有 HTTP 网络请求。390 宽度下的长网址溢出已修复并回归。

窗口覆盖 1440×1000、1180×760、900×650 和 390×844；检查页面与弹窗无横向溢出，并人工查看截图。Tauri 当前主窗口最小宽度为 940，390 宽度是额外的浏览器布局压力检查，不代表已交付移动端应用。

演示截图在[使用指南](模型配置与界面使用指南.md)及 `docs/images/`。它们不含真实 Key、会话或余额。界面回归不会调用真实桌面 IPC，也不会改写用户的 Codex/Claude 配置。

## 真实只读探测

读取当前用户的 `LLMGW_LIVE_*` 环境变量，在本轮 Cargo 编译完成对应测试二进制后直接执行其中的 ignored 测试。此方式避免重复编译；可复现的 Cargo 命令见下方。没有发送聊天请求或输出凭据/余额数值。

| 探测 | 结果 |
| --- | --- |
| OpenRouter 模型目录 | 成功，返回非空模型列表 |
| SenseNova 模型目录 | 成功，返回非空模型列表 |
| OpenRouter `/key` | 成功，解析 1 个 Key 额度项目及 1 个 Key 有效期项目；有效期项目可表示未设置到期时间，不代表订阅信息 |
| Air Outer 额度 | 返回 `unsupported`，未取得已识别的额度/订阅结构；要求返回 `ok` 的真实探测断言失败，不能标记为已支持 |

本轮四个真实只读测试为 3 通过、1 未通过。它们与不依赖外部服务的常规回归分别记录。未实网验证 DeepSeek、New API、Sub2API 账户；这些解析通过本地协议夹具验证。SenseNova、智谱等官网余额未被宣称已支持。目录存在不保证每个模型可用，免费价格也不保证当前账户仍有免费请求额度。

复现只读探测时，先将本机 User 级对应环境变量加载到当前进程；不应把变量值写入脚本或提交到 Git：

```powershell
cd src-tauri
cargo test --jobs 1 --test model_catalog -- --ignored --nocapture
cargo test --jobs 1 --test provider_quota -- --ignored --nocapture
```

## 已知边界

额度接口由平台开放情况、部署版本及 Key 权限决定。上游仅返回模型消费时只能展示已用值；没有模型总限额，就无法可靠计算剩余量。当前不会登录网站、抓取 Cookie、猜测汇率或自动改变路由优先级。

配置备份回归在独立临时目录完成，不拿用户的真实客户端配置做写入测试。多个客户端文件不是跨文件事务；写入阶段失败会返回全部已验证备份路径，方便恢复。新建文件没有可备份的原件，结果会明确标记。
