## 完成的修复

- 外部 mojie 面板首次请求合并（含 React StrictMode effect 重放），刷新按请求代次防乱序；IPC 异常显示可重试原因并清除旧值。浏览器旧逻辑重复探测 4 次，新逻辑仅 1 次；迟到响应和异常回归均通过。
- 外部控制器必须使用回环地址与 1–65535 端口，支持带 YAML 注释的地址；订阅 URL 使用 JSON 字符串解码，拒绝 URL 用户口令及片段。递归解析 `MoJie/GLOBAL` 选择组并防环；分组不再当作物理节点，0 延迟作为未知而不是最快节点。
- WorkBuddy/Trae 健康检查读取实际渲染进程 API；CDP 连接、请求与关闭均有有界处理，生成开始后不转到另一页面重放。非法消息、工具、多模态或未知模型返回 400，超过 1 MiB 返回 413。
- WorkBuddy 错误、空内容或缺少 `[DONE]` 的 SSE 返回失败。Trae 修正首次回复秒/毫秒判定，拒绝并发 UI 生成和已有输入草稿；使用诚实的 `trae-desktop` 入口。
