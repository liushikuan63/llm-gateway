### B3 本地客户端用量的实现约定

1. 支持目标先覆盖用户点名的 Codex、dsh、Qoder。只读取已识别的日志目录，按需扫描；不开后台全机监听，不读取凭据配置，不上传日志，不保存对话正文。不同版本日志不能识别时明示，不猜 token。
2. 输出按来源、模型、统计时段分组；至少包含输入、输出、缓存读取 token，有缓存写入字段时另列。缓存命中按记录区分“读取 token > 0 / 明确为 0 / 未知”，提供三类数量。保留字段缺失与真实 0 的区别；缓存 token 是否包含在输入内按来源口径说明，不能再次加进总量。
3. 累计用量事件和单次用量事件分别处理；同一请求的重复通知、流式快照、重复日志文件、模型切换和计数重置必须有对照夹具。没有可靠去重标识时说明边界。
4. 本地日志统计不直接写网关 requests/spend 表、不扣网关 Key 预算，也不与网关审计作无条件合计。客户端直连和经网关调用都可能留下日志，没有同源请求 ID 无法保证跨来源去重。
5. 扫描有文件数、文件/行大小、总字节和时间边界；返回已读、跳过、坏行和截断状态。取消、文件正在追加、文件被删除/拒绝读取时仍给出明确部分结果，界面不会让旧扫描覆盖新条件。
6. 用真实本机日志作只读字段核对和汇总验证；测试夹具只保留合成 ID、公开模型名、时间和数字。真实日志及其正文不作为仓库夹具或交付文件。
